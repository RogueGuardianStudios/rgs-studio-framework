# Brief: Template System

## Assigned Agent
Simulated Agent (governed by agents/simulated-agent.md)

## Task
Build a template system for generating Brief documents.
It should read template files, fill in placeholders, and
produce ready-to-use Brief markdown.

## Language
JavaScript (Node.js, ES modules)

## Location
src/brief-engine/

## What We Need
- A way to fill in templates with values
- A way to see what placeholders a template expects
- A sample template that works with the system

## Implementation Standards
- TDD
- Document public API
- ES modules

## Success Condition
The template system works and is tested.
