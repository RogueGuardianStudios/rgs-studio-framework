# Rogue Guardian Studios — Agent Brief
# This document is the standard handoff format between agents.
# All fields are required unless marked optional.
# Brevity is a requirement, not a preference. If it does not
# need to be here, it is not here.

## Context Summary


What is happening and why. Two to four sentences maximum.
No history. No justification. Just the current situation
the receiving agent needs to understand.


---

## Success Condition


What does done look like for the receiving agent?
One to three sentences. Specific and testable.


---


## Handoff Notes


Optional. Anything that does not fit the above categories
but the receiving agent genuinely needs to know.


---


## Receiving Agent Acknowledgement


The receiving agent must complete this section before
beginning work. Do not start until this is signed.


- [ ] I have read this Brief in full
- [ ] I have read values.md and evaluation-rubric.md
- [ ] I understand the locked decisions and will not
      revisit them without escalating
- [ ] I understand my escalation triggers
- [ ] I understand the success condition and accept it
      as my definition of done


Acknowledged by: [Receiving agent name/role]
Date: [YYYY-MM-DD]


---


## Transmitting Agent Sign-Off


To be completed by the transmitting agent once the
receiving agent confirms the task is done. The transmitting
agent confirms the outcome resolves the original issue.


- [ ] The receiving agent's output meets the success condition
- [ ] The issue that prompted this handoff is resolved
- [ ] If the issue is not fully resolved, an updated Brief
      or escalation has been issued


Confirmed by: [Transmitting agent name/role]
Date: [YYYY-MM-DD]
